## 异步加载概念教学（19:17，口头讲解，未改码）
- 用 3 张可视化讲：①同步 vs 异步帧时间线（WaitForCompletion=主线程忙等=掉帧）②AsyncOperationHandle 状态机（发起→等待 IsDone→Completed→Result→使用→Release；yield/Completed/await.Task 三写法等价，他项目 UpdateMgr 用 yield、AddressablesMgr 用 Completed）③预热心法（加载时机前移到加载画面/波次前，异步+池预填充合体）
- 三个坑：异步≠不卡（Instantiate 等主线程活仍占帧，需配池）；async/sync 同 key 混用必踩重复 Add；异步资源不 Release 永久驻留（"每 key 一次+常驻+ClearPool 显式清场"是最省心模型）
- 判断标准：加载点在玩家操作路径上就绝不能同步；启动/切场景/波前→预热；纯内存查询无所谓
