## 项目整体框架梳理（用户要求了解代码结构）
- 项目：Unity 2022.3.62f3c1 塔防游戏（原名 UnityTeachDemo3），C# 手写逻辑 + Asset Store 美术资源。
- 结构：Assets/{Scripts 逻辑, Resources 动态加载, Scenes(主菜单+3关卡), StreamingAssets 4个JSON数值表, ArtRes 美术包}。
- 关键脚本：Main.cs 入口 → UIManager(BeginPanel) → ChooseHero → ChooseScene → GameLevelMgr。核心对象：PlayerObject/MonsterObject(NavMesh)/TowerObject/MainTowerObject。
- 数值全在 JSON（RoleInfo/MonsterInfo/TowerInfo/SceneInfo），数据驱动 + 单例模式（GameDataMgr/GameLevelMgr/UIManager/BKMusic）。

## ArtRes 素材包与 _TerrainAutoUpgrade 详细解析（用户后续要复用素材）
- `_TerrainAutoUpgrade/`：4 个 .terrainlayer（Unity 2022 地形系统自动升级产物，引用地面贴图，TileSize 10），不能随意删。
- ArtRes 各包：Excel(4个策划xlsx)、Font(FZSTK中文字体+INKFREE英文手写体)、GabrielAguiarProductions(Unique_Projectiles_Volume_1 投射物特效: Hits/Muzzle/Projectiles)、MagicArsenal(魔法特效15类: Aura/Beams/Charge/Cleave/DOT/Enchant/Muzzleflash/Projectiles/Shields/Slash/SphereBlast/Sprays等+37个wav)、PureNature(自然环境: Architecture/Banks/Rocks/Vegetation/WaterFall, 含Environment Manager, URP+内置双版本)、Toon_Soldiers(8兵种士兵: engineer/flammer/gunner/infantry/medic/officer/scout/sniper, 主模型ToonSoldiers_customizable.FBX)、Toon_Zombies_extended(僵尸: male/female_civilians+specials, 动画5状态: Aggresive/Broken/Calm/Crawl/Generic)、Top-Down Graveyard(墓地场景: Demo1/Demo2_mobile/Prefabs/_Origin, 含12个terrainlayer)、Tower Defense(15种塔x3级: Acid/Cannon/Crossbow/Crystal/Fire/Gatling/Gauss/Hammer/Laser/Mortar/Plasma/Radar/Rocket/Tesla; Grounds地面贴图带冬季版; Prefabs_props大量场景道具; 含旧版Standard Assets)。
- 实际引用关系：Resources/Tower/1_1 → Tow_Acid1.fbx；Resources/Role/1 → Toon_Soldiers weapon_knife.FBX；Resources/Monster/Z1 → TZ_Hulk_body_04。
